Format för förbrukningsfil

Importera JSON eller CSV från elmätare/elhandlare med tidsstämpel för kvartets start och förbrukning i kWh. Exempel på JSON:

[{"time_start":"2026-11-10T12:00:00+01:00","usage_kWh":0.42}]

JSON kan också vara ett objekt med en data-lista. CSV ska ha rubrikerna time_start och usage_kWh (eller timestamp och kWh). Tidsstämpeln behöver innehålla tidszon. Mätvärden sparas lokalt i den här webbläsaren.
